Welcome to the OpenAware Navigator! Please note that this is still a work in progress.

The navigator can be used by researchers and data management professionals to decide what are best practices for making research open, reproducible, transparent and reusable as much as possible even when there are restrictions for data sharing.

The OpenAware Navigator was created during the Open Science Retreat Netherlands 2026 by Mark van Assem, Lotte van Burgsteden, Rianne Fijten, Jack Fitzgerald, Bogdana Huma, Santosh Ilamparuthi, Angelica Maineri.

Please note that the Navigator has been developed in the Netherlands, and most of the resources listed are mainly available to Dutch-affiliated researchers. If you are interested in adapting this work to your own context, you are welcome to use this a template.

To access the tool, please visit https://jack-fitzgerald.shinyapps.io/OpenAware_Navigator/

This tool was created using SurveyDown (Hu, Bunea, & Helveston 2025). To adapt our tool for your institution's needs, see our source files and the SurveyDown documentation at https://surveydown.org/

Hu, P., Bunea, B., & Helveston, J. P. (2025). "surveydown: An open-source, markdown-based platform for programmable and reproducible surveys." PLoS One 20(8), e0331002. https://doi.org/10.1371/journal.pone.0331002
